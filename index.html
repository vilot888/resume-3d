01

实验数据批处理与报告自动生成工具

Python 命令行工具 · 把多份原始记录整理成规范报告
Pythonpandasopenpyxlpython-docx

实验课每次都要从仪器导出的十几份 CSV / Excel 里手工挑数、算平均值与偏差、再复制粘贴进 Word 模板。我把这套流程写成了一个命令行工具。

  • 多源汇总：自动识别表头位置并统一成同一套字段名，仪器导出格式变了也不用改代码，改配置就行
  • 规则外置：清洗与计算规则写在 YAML 里（去重、量程校验、缺失值策略、公式），换一门课只换配置
  • 大文件不炸内存：用 pandas 分块读取，几百 MB 的日志也能跑完
  • 报告自动化：用 python-docx 填充 Word 模板，一次运行输出全部数据表 + 图表 + 结论页
  • 异常可追溯：被剔除的样本单独落盘并记录原因，不用回去翻原始文件
结果原来一份实验报告要反复复制粘贴很久，现在一条命令跑完；规则改动不再需要动代码。
02

校园图书借阅管理系统

Java 课程设计 · 图书 / 读者 / 借还 / 逾期
JavaJDBCMySQL分层架构

面向图书馆日常借还的业务系统，重点不在界面，而在把借阅这件事的规则写对、写清楚。

  • 分层拆分：Controller / Service / DAO 各管一段，SQL 只出现在 DAO，业务判断集中在 Service，出问题不用满项目找
  • 借阅状态机：在馆 → 借出 → 逾期 → 归还，状态迁移写成明确的方法，非法迁移直接抛异常而不是悄悄改数据
  • 并发下不超借：同一本书被两个人同时点借出时，用数据库唯一约束 + 事务兜住，而不是只靠界面上的判断
  • 逾期计算：按借期与归还日期算罚金，边界（当天归还、跨月、续借）都有单独用例
  • 可测试：核心借还逻辑抽成不依赖数据库的纯方法，能直接写单测跑
结果把原来散落在界面事件里的判断收敛到 Service，逻辑改一处就能全站生效，也更敢改动。
03

课堂行为识别的轻量迁移学习实践

AI 应用 · 用普通摄像头做举手 / 低头识别与统计
PythonPyTorchONNXOpenCV

想让老师不用回头就能看到后排谁在举手。重点不是刷指标，而是走通「数据 → 训练 → 导出 → 在普通电脑上跑起来」这条链。

  • 小样本起步：先用公开数据集预训练，再拿自己标注的课堂截图做迁移学习，避免从零训练
  • 数据增强：随机裁剪、亮度扰动、水平翻转，缓解标注量少和光照差异大的问题
  • 导出 ONNX 落地：训练完导出 ONNX，用 OpenCV DNN 推理，不依赖训练环境也能部署
  • 时序平滑：单帧结果用滑动窗口投票再输出，避免手晃一下就误判成举手
  • 置信度兜底：低置信度不硬判，标成「不确定」交给规则处理，而不是给个看起来确定的错答案
收获把 AI 需求拆成「模型能不能解」和「工程怎么接」两层分别评估——很多坑其实在第二层。
