校园图书借阅管理系统

Java 课程设计，面向图书馆日常借还的业务系统。

  • 借阅状态机：在馆 → 借出 → 逾期 → 归还，非法迁移直接抛异常
  • 并发下不超借：数据库唯一约束 + 事务兜住，而不是只靠界面判断

  • 可测试：核心借还逻辑抽成不依赖数据库的纯方法，能直接写单测

结果　散落在界面事件里的判断收敛到 Service，改一处全站生效。
